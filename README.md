# Blog

A simple blog application built with React. The blog is responsive, so elements adapt to the size of the screen. 

## Features
It is possible to
* Specify your name
* Create Posts
* Edit Posts
* Delete Posts

## Live Demo
Visit: https://blog-with-react-b3fz.onrender.com/

## Installation
```bash
git clone https://github.com/OverlordGummyBear/Blog-with-React.git
cd Blog-with-React/BlogWithReact
npm i
npm run dev
```

## Usage
Open the URL shown in your terminal (usually http://localhost:5173/) in your browser to view the blog
